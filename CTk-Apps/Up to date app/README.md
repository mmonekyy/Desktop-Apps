# How it works 

The application works by placing code modules into a folder named modules. Each module must include a function called main(frame_right), which contains the code responsible for a specific functionality. For example, a module named password.py might provide password-related features.

## 📁 App Structure

```
main.py
modules/
└── password.py
```
